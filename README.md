## ⚙️ Running Locally
To run this portfolio on your local machine:
1. Clone the repository: `git clone https://github.com/Anthony-okonkwo/myportfolio.git`
2. Navigate into the directory: `cd your-repo-name`
3. Install dependencies: `npm install`
4. Start the dev server: `npm run dev`
